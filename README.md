# QA API Testing

Учебный QA-проект по тестированию REST API.

## О проекте

В рамках проекта проводится тестирование REST API для работы с пользователями.

API позволяет:

- получать список пользователей;
- создавать пользователей;
- изменять данные пользователей;
- удалять пользователей.

## Технологии и инструменты

- Postman
- MySQL
- SQL
- Node.js
- Express
- Git
- GitHub

## API endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/users` | Получение списка пользователей |
| POST | `/users` | Создание пользователя |
| PATCH | `/users/:id` | Изменение пользователя |
| DELETE | `/users/:id` | Удаление пользователя |

## Что тестируется

- позитивные сценарии;
- негативные сценарии;
- валидация входных данных;
- HTTP status codes;
- обработка ошибок;
- уникальность email;
- работа с базой данных;
- соответствие данных API данным в MySQL.
