# QA API Testing

Учебный QA-проект по тестированию REST API для работы с пользователями.

## О проекте

В рамках проекта проводится функциональное и негативное тестирование REST API.

API позволяет:

* получать список пользователей;
* создавать пользователей;
* изменять данные пользователей;
* удалять пользователей.

Тестирование выполняется с использованием Postman, SQL и MySQL.

## API endpoints

| Method | Endpoint     | Description                    |
| ------ | ------------ | ------------------------------ |
| GET    | `/users`     | Получение списка пользователей |
| POST   | `/users`     | Создание пользователя          |
| PATCH  | `/users/:id` | Изменение данных пользователя  |
| DELETE | `/users/:id` | Удаление пользователя          |

## Что тестируется

В проекте проверяются:

* позитивные сценарии;
* негативные сценарии;
* валидация входных данных;
* граничные значения;
* HTTP status codes;
* обработка ошибок;
* уникальность email;
* работа с базой данных;
* соответствие данных API данным в MySQL;
* автоматические проверки в Postman.

## Тестирование POST /users

На данный момент протестированы следующие сценарии:

* создание пользователя с валидными данными;
* создание пользователя с уже существующим email;
* проверка минимального допустимого возраста;
* проверка максимального допустимого возраста;
* проверка возраста ниже допустимого диапазона;
* проверка возраста выше допустимого диапазона;
* создание пользователя без имени;
* создание пользователя без email.

Проверяемые HTTP status codes:

* `201 Created` — успешное создание пользователя;
* `400 Bad Request` — некорректные или отсутствующие данные;
* `409 Conflict` — попытка использовать существующий email.

Для части негативных сценариев используются автоматические проверки Postman с помощью JavaScript.

## Postman

Коллекция Postman находится в файле:

`QA_API.postman_collection.json`

Коллекцию можно импортировать непосредственно в Postman.

Автоматические проверки выполняются с помощью `pm.test()`.

Пример проверок:

* HTTP status code;
* сообщение об ошибке;
* корректность данных ответа.

## Работа с базой данных

Для хранения данных используется MySQL.

Проверяется соответствие данных между API и базой данных.

Используемые SQL-инструменты:

* `SELECT`
* `WHERE`
* `ORDER BY`
* `INSERT`
* `UPDATE`
* `DELETE`

## Как запустить API

Установить зависимости:

```bash
npm install
```

Запустить сервер:

```bash
npm start
```

После запуска API доступно по адресу:

```text
http://localhost:3000
```
